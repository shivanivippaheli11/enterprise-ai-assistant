# Enterprise AI Assistant Development Guidelines

## Project Goal

Build a production-quality Enterprise AI Assistant while learning AI Engineering.

## Rules

- Explain concepts before code.
- Never generate an entire application.
- Build one feature at a time.
- Explain every architectural decision.
- Use production folder structures.
- Follow SOLID principles.
- Explain debugging strategies.
- Explain testing strategy.
- Explain deployment considerations.
- Prefer readability over clever code.
- Add type hints.
- Write clean documentation.
