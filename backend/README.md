# Backend

This backend currently contains a minimal Python sample for the Enterprise AI Assistant.

## Run Locally

1. Create and activate a virtual environment.
2. Install dependencies with `pip install -r requirements.txt`.
3. Run the sample with `python app/main.py` from the `backend` directory.

## Current Modules

- `app/models/chat_request.py` validates incoming chat request data.
- `app/models/chat_response.py` represents the generated response payload.
- `app/main.py` demonstrates creating and printing a request and response.
