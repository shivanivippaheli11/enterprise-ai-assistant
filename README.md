# Enterprise AI Assistant

This repository contains the starter structure for an enterprise-focused AI assistant project.

## Current Scope

- Backend domain models for chat request and response objects.
- Project documentation for the roadmap, vision, and engineering guidelines.
- A simple Python entrypoint that demonstrates model usage.

## Repository Structure

- `backend/` contains the Python application code.
- `docs/` contains project planning and engineering guidance.
- `frontend/` is reserved for the future UI implementation.

## Next Steps

1. Add API endpoints with FastAPI.
2. Introduce tests for the backend models and request flow.
3. Connect the backend to an LLM service and enterprise data sources.
